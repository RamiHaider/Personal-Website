Introduction

In a previous section, we learned about neural networks. Convolutional neural networks, the backbone of computer vision, are simply just adding a convolutional part before the fully connected layer - It really is just that simple. Let's learn how a forward pass through a trained CNN works, within a geophysical context.

Model input

Say we trained a model to classify geophysical images as containing mineralization or not. Now, we want to input an image to this model to know if it contains mineralization or not.

The image dimensions in pixel width and height should be consistent with what size dimensions the model was trained on. In this case, we're using a 32×32 pixel region as input to our model.

RGB Decomposition

Using color positively affects the model results, but for visualization purposes, we will only process the Red channel. However, in practise for RGB images, we decompose the image in its 3 channels, and a 3D tensor, each dimension representing a channel gets fed to the model.

let's choose the red channel for visualization purposes.

Next, normalize intensity values from 0-255 to 0-1

3First Layer: Feature Mapping (Convolution)

Video: 0:59 - 1:08

Now comes the key step that gives convolutional neural networks their name: convolution. During training, the model learns filters—basically, small 3×3 matrices—that slide over the image to extract features. These filters end up being edge detectors or pattern detectors, and they're common across many use cases—cats, cars, geophysical maps, you name it.

At the highest level of abstraction, images are just edges and shapes. So at the start of the process, the filters are typically detecting edges. We pass each 3×3 filter over the input grid—starting top-left, moving across, then down—and for each step, we multiply the filter values with the image values element-wise. Then we sum them up and record that result in a new matrix, which we call a feature map.

We're not downsampling yet—we're just doing convolutions. Each filter gives us one feature map. In this case, we're using three filters, so we get three output maps.

4ReLU Activation & Max Pooling

Video: 1:09 - 1:16

Next, we apply the ReLU activation function. It's simple—just replaces any negative value with zero. This introduces non-linearity, which is crucial because otherwise, the network would just be a linear function and wouldn't be able to model complex patterns.

After ReLU, we apply max pooling, which is a form of downsampling. We take a 2×2 grid and replace it with its maximum value. This reduces the size of our feature maps, which helps with computation, prevents overfitting, and retains the most important features.

Why This Matters: Max pooling introduces translation invariance—meaning the network can recognize features regardless of their exact position in the image.

5Second Layer: Advanced Feature Detection

Video: 1:18 - 1:24

That completes the first layer of inference. Now those three downsampled maps become the input for the next layer, which contains six filters. We repeat the same process: convolution with the new filters, apply ReLU, and do max pooling.

The network is now starting to detect more abstract patterns by combining features from the previous layer. Where the first layer detected simple edges, this layer can detect more complex shapes and textures.

6Second Layer: ReLU & Max Pooling

Video: 1:25 - 1:32

Again, we apply ReLU activation followed by max pooling to our six feature maps from the second convolutional layer. This further reduces the spatial dimensions while preserving the most important features detected by our filters.

At this point, our network has learned to identify increasingly complex patterns and features that are relevant for mineral deposit detection.

7Flattening: From Images to Vector

Video: 1:34 - 1:41

Once we're done with the second layer, we flatten the outputs into a column vector. Say we have six feature maps, each 6×6—that's 216 values total. We reshape them into a 216-length vector.

This vector gets passed into the fully connected layers. This step is crucial as it transforms our 2D feature maps into a 1D format that traditional neural network layers can process.

8Fully Connected Layers & Prediction

Video: 0:39 - 0:45

In the fully connected layer, each input node is connected to every node in the next layer. This is where the real "decision-making" happens. What's actually going on under the hood is that these operations are all vectorized and parallelized—handled efficiently using Python libraries that are really just wrappers over optimized C, C++, or Fortran code.

From there, we pass the data through a few more hidden layers—again, already trained—and eventually reach the output layer.

At the end of it all, the model gives us a prediction: a probability that the selected region contains a mineral deposit. Each weight in the network represents how important a certain part of the image was in making that prediction. That's really what training a model is all about—finding out which pixels or patterns matter.

The Math Behind It: The fully connected layers perform matrix multiplication followed by activation functions, essentially learning complex non-linear relationships between the extracted features and the final predictions.

Putting It All Together

This visualization demonstrates how a CNN transforms raw geophysical data into meaningful predictions through a series of mathematical operations. From simple edge detection to complex pattern recognition, each layer builds upon the previous one to create increasingly sophisticated understanding.

The power of CNNs lies in their ability to automatically learn relevant features from data, making them incredibly effective for computer vision tasks across many domains—from medical imaging to autonomous vehicles to geological exploration.
