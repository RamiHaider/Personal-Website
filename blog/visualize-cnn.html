How CNNs Actually Work: A Visual Journey

Published: January 25, 2025

Reading Time: ~8 minutes

"If you're interested—like me—in how computer vision works, this is for you."

I'm a very visual learner, so I created a dynamic visualization to help me understand how a computer actually recognizes things. At the end of the day, it's all done through math. This visualization operates at a pretty high level, but it's still going to give you a much better grasp of how things work.

We're going to walk through how a common convolutional neural network architecture processes images. This architecture is the backbone of computer vision. To explain it, I'll show you an example from one of the technologies I created: a geospatial mineral deposit targeting software.

1

From Pixels to Patterns

The first thing you're seeing here is airborne geophysical data. This is an inferencing visualization—meaning the model has already been trained. The weights and filters have already been determined. We're simply passing new data through this little brain we've built, and it's making predictions based on what it already learned.

🎯 Key Insight

Watch how the model selects a region of interest. It's important that this input image has the same size and resolution as what the model was trained on—the closer the match, the better the results.

In our case, the output is a probability of a mineral occurrence. What we've done is associate geophysical images with mineral potentials. If you've got a keen eye, you'll notice this visualization only shows images. In future posts, I'll show how we integrate geochemical and geological data to make inferences about gold, copper, and silver.

2

Simplifying Color Channels

The image starts in RGB format—three channels: red, green, and blue. But to keep things simple for visualization, we'll focus on just one channel. In this case, we've randomly picked the red channel.

Instead of rendering it in red, we convert its values into grayscale intensities. Behind the scenes, it's still red channel data, just visualized in black and white. This conversion transforms color information into numerical intensities that the neural network can process mathematically.

Technical Note: Each pixel value is normalized to a range of 0-1, where 0 represents black (no intensity) and 1 represents white (maximum intensity). This normalization helps the neural network train more effectively.
3

The Heart of CNNs: Convolution

Now comes the key step that gives convolutional neural networks their name: convolution. During training, the model learns filters—basically, small 3×3 matrices—that slide over the image to extract features.

🔍 Pattern Detection

These filters end up being edge detectors or pattern detectors, and they're common across many use cases—cats, cars, geophysical maps, you name it. At the highest level of abstraction, images are just edges and shapes.

We pass each 3×3 filter over the input grid—starting top-left, moving across, then down—and for each step, we:

1. Position Filter

Place 3×3 filter on image section

2. Element-wise Multiply

Multiply filter × image values

3. Sum Results

Add all products together

4. Record Output

Store result in feature map

We're not downsampling yet—we're just doing convolutions. Each filter gives us one feature map. In this case, we're using three filters, so we get three output maps.

Next, we apply the ReLU activation function. It's simple—just replaces any negative value with zero. This introduces non-linearity, which is crucial because otherwise, the network would just be a linear function and wouldn't be able to model complex patterns.

After ReLU, we apply max pooling, which is a form of downsampling. We take a 2×2 grid and replace it with its maximum value. This reduces the size of our feature maps, which helps with computation, prevents overfitting, and retains the most important features.

4

Building Complex Features

That completes the first layer of inference. Now those three downsampled maps become the input for the next layer, which contains six filters. We repeat the same process: convolution with the new filters, apply ReLU, and do max pooling.

🧠 Abstract Pattern Recognition

The network is now starting to detect more abstract patterns by combining features from the previous layer. While the first layer detected simple edges, the second layer can recognize corners, textures, and more complex shapes.

This hierarchical feature extraction is what makes CNNs so powerful. Each layer builds upon the previous one, creating increasingly sophisticated representations of the input image.

5

From Images to Decisions

Once we're done with the second layer, we flatten the outputs into a column vector. Say we have six feature maps, each 6×6—that's 216 values total. We reshape them into a 216-length vector. This vector gets passed into the fully connected layers.

Behind the Scenes: What's actually going on under the hood is that these operations are all vectorized and parallelized—handled efficiently using Python libraries that are really just wrappers over optimized C, C++, or Fortran code.

In the fully connected layer, each input node is connected to every node in the next layer. This is where the real "decision-making" happens. From there, we pass the data through a few more hidden layers—again, already trained—and eventually reach the output layer.

⚡ The Magic of Training

Each weight in the network represents how important a certain part of the image was in making that prediction. That's really what training a model is all about—finding out which pixels or patterns matter.

6

The Final Prediction

At the end of it all, the model gives us a prediction: a probability that the selected region contains a mineral deposit. In this visualization, you'll see predictions for different minerals like Gold, Copper, and Iron, each with their confidence levels.

This entire process—from pixel to prediction—happens in milliseconds. The beauty of CNNs lies in their ability to automatically learn hierarchical representations without explicitly programming what features to look for.

You've just witnessed how a convolutional neural network transforms raw pixels into meaningful predictions. From simple edge detection to complex pattern recognition, CNNs represent one of the most elegant solutions in artificial intelligence.
